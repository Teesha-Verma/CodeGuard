# Retrieval Summary
OWASP ASVS V12.1.1 requires secure file upload & path sanitization. This verification rule ensures applications enforce prevent arbitrary code execution and path traversal via malicious file uploads. to prevent uploading executable scripts (e.g. `.py`, `.php`) to web-accessible directories allows remote attackers to execute code on server. across Python web frameworks including FastAPI, Flask, and Django.

# Overview
Verify that uploaded files are validated for type, renamed with generated UUIDs, and stored outside the web root.

# Official Requirement
Verify that the application complies with OWASP ASVS V12.1.1 (V12 File & Resources): Verify that uploaded files are validated for type, renamed with generated UUIDs, and stored outside the web root.

# Security Objective
Prevent arbitrary code execution and path traversal via malicious file uploads.

# Why This Matters
Uploading executable scripts (e.g. `.py`, `.php`) to web-accessible directories allows remote attackers to execute code on server.

# Threat Model
Attacker uploads `shell.py` or filename `../../etc/passwd` to overwrite critical system files.

# Detection Guidance
AI code reviewers should scan Python source files for unvalidated usage of werkzeug.utils.secure_filename, uuid.uuid4, path.join. Look for missing authorization, improper type checking, or un-parameterized dynamic input.

# AST Detection Hints
Target AST nodes: `ast.Call (save, open, write, UploadFile)`. Scan function definitions and calls matching these nodes.

# Regex / Search Hints
Use regex pattern: `(?i)\.save\(\s*file\.filename\)` to flag candidate vulnerabilities.

# Semantic Detection Hints
Saving user-uploaded files directly using original filename without sanitization or UUID re-naming.

# Relevant Python APIs
`werkzeug.utils.secure_filename, uuid.uuid4, path.join`

# Relevant Imports
`import uuid, os, from werkzeug.utils import secure_filename`

# Vulnerable Patterns
Insecure implementation exposing security flaws:
```python
@app.post('/upload')
def upload(file: UploadFile):
    with open(f'/var/www/uploads/{file.filename}', 'wb') as f: f.write(file.file.read())
```

# Secure Patterns
Secure implementation fulfilling ASVS V12.1.1:
```python
@app.post('/upload')
def upload(file: UploadFile):
    ext = os.path.splitext(file.filename)[1].lower()
    if ext not in ('.jpg', '.png'): raise HTTPException(400)
    name = f'{uuid.uuid4()}{ext}'
    with open(os.path.join('/var/app_storage', name), 'wb') as f: f.write(file.file.read())
```

# FastAPI Example
```python
@app.post('/upload')
def upload_file(file: UploadFile = File(...)):
    ext = os.path.splitext(file.filename)[1].lower()
    if ext not in ('.png', '.jpg'): raise HTTPException(400)
    filename = f'{uuid.uuid4()}{ext}'
    dest = os.path.join('/tmp/uploads', filename)
    with open(dest, 'wb') as buffer: shutil.copyfileobj(file.file, buffer)
```

# Flask Example
```python
@app.route('/upload', methods=['POST'])
def upload():
    f = request.files['file']
    safe_name = f'{uuid.uuid4()}_{secure_filename(f.filename)}'
    f.save(os.path.join('/var/uploads', safe_name))
```

# Django Example
```python
def handle_upload(request):

    default_storage.save(f'uploads/{filename}', f)
```

# Common Developer Mistakes
Validating Content-Type header only, which can be spoofed easily by client tools.

# False Positives
Internal administrative document importers accepting strictly controlled files in locked subnets.

# False Negatives
Sanitizing filename but saving file into web server root directory configured to execute scripts.

# AI Review Heuristics
Flag any file write operation using `file.filename` directly without UUID generation or path sanitization.

# Detection Confidence
Confidence level: **HIGH**

# Reasoning Chain
Inspect file upload target path construction and check if filename is generated via UUID.

# Review Checklist
- [ ] Verify requirement ASVS V12.1.1 is enforced in code.
- [ ] Confirm automated unit tests validate this constraint.
- [ ] Ensure secure default fallback if validation fails.

# Remediation
Rename all uploads with UUIDs, restrict allowed extensions, and store files outside public web root.
