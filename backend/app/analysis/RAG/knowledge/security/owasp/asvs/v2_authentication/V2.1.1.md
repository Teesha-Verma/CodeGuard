# Retrieval Summary
OWASP ASVS V2.1.1 requires password length & complexity verification. This verification rule ensures applications enforce enforce strong user password policies that withstand brute-force attacks and dictionary matching. to prevent short passwords are susceptible to offline brute-force attacks and dictionary matching. across Python web frameworks including FastAPI, Flask, and Django.

# Overview
Verify that user passwords are required to be at least 12 characters in length and checked against compromised credential lists.

# Official Requirement
Verify that the application complies with OWASP ASVS V2.1.1 (V2 Authentication): Verify that user passwords are required to be at least 12 characters in length and checked against compromised credential lists.

# Security Objective
Enforce strong user password policies that withstand brute-force attacks and dictionary matching.

# Why This Matters
Short passwords are susceptible to offline brute-force attacks and dictionary matching.

# Threat Model
Attacker uses automated credential stuffing to compromise accounts using common short passwords.

# Detection Guidance
AI code reviewers should scan Python source files for unvalidated usage of len(), passlib.hash.argon2, werkzeug.security.check_password_hash. Look for missing authorization, improper type checking, or un-parameterized dynamic input.

# AST Detection Hints
Target AST nodes: `ast.Compare, ast.Call (len, check_password, validate_password)`. Scan function definitions and calls matching these nodes.

# Regex / Search Hints
Use regex pattern: `(?i)len\(\s*password\s*\)\s*<\s*(8|10|12)` to flag candidate vulnerabilities.

# Semantic Detection Hints
Weak password length validations allowing passwords under 12 characters.

# Relevant Python APIs
`len(), passlib.hash.argon2, werkzeug.security.check_password_hash`

# Relevant Imports
`from passlib.hash import argon2, import re`

# Vulnerable Patterns
Insecure implementation exposing security flaws:
```python
def validate_password(p):
    if len(p) < 6: raise ValueError('Short')
```

# Secure Patterns
Secure implementation fulfilling ASVS V2.1.1:
```python
def validate_password(p):
    if len(p) < 12: raise ValueError('Must be 12+ chars')
```

# Python Example
```python
def validate_password(p):
    if len(p) < 12: raise ValueError('Must be 12+ chars')
```

# FastAPI Example
```python
class UserReg(BaseModel):
    password: str = Field(..., min_length=12)
```

# Flask Example
```python
if len(request.json.get('password', '')) < 12: return jsonify({'error': 'Too short'}), 400
```

# Common Developer Mistakes
Restricting password character sets or enforcing arbitrary truncation.

# False Positives
Custom password strength estimators like zxcvbn enforcing entropy instead of strict character counts.

# False Negatives
Checking password length on hashed strings instead of raw password inputs.
