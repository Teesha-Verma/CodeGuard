# Retrieval Summary
OWASP ASVS V6.2.1 requires strong cryptographic algorithm selection. This verification rule ensures applications enforce ensure stored sensitive data and passwords use industry-standard algorithms resilient to cryptanalysis. to prevent legacy ciphers (des, rc4) and weak hash functions (md5, sha1) are vulnerable to rapid decryption and collision attacks. across Python web frameworks including FastAPI, Flask, and Django.

# Overview
Verify that strong cryptographic algorithms (such as AES-256-GCM or Argon2id) are used for encryption and hashing.

# Official Requirement
Verify that the application complies with OWASP ASVS V6.2.1 (V6 Stored Cryptography): Verify that strong cryptographic algorithms (such as AES-256-GCM or Argon2id) are used for encryption and hashing.

# Security Objective
Ensure stored sensitive data and passwords use industry-standard algorithms resilient to cryptanalysis.

# Why This Matters
Legacy ciphers (DES, RC4) and weak hash functions (MD5, SHA1) are vulnerable to rapid decryption and collision attacks.

# Threat Model
Attacker steals hashed password database and cracks MD5 hashes in minutes using GPU rainbow tables.

# Detection Guidance
AI code reviewers should scan Python source files for unvalidated usage of hashlib.pbkdf2_hmac, cryptography.hazmat.primitives.ciphers.aead.AESGCM, argon2.PasswordHasher. Look for missing authorization, improper type checking, or un-parameterized dynamic input.

# AST Detection Hints
Target AST nodes: `ast.Call (hashlib.md5, hashlib.sha1, DES.new)`. Scan function definitions and calls matching these nodes.

# Regex / Search Hints
Use regex pattern: `(?i)(md5|sha1|DES|RC4)\(` to flag candidate vulnerabilities.

# Semantic Detection Hints
Use of deprecated cipher suites or non-salted hash functions for password storage.

# Relevant Python APIs
`hashlib.pbkdf2_hmac, cryptography.hazmat.primitives.ciphers.aead.AESGCM, argon2.PasswordHasher`

# Relevant Imports
`from cryptography.hazmat.primitives.ciphers.aead import AESGCM, from argon2 import PasswordHasher`

# Vulnerable Patterns
Insecure implementation exposing security flaws:
```python
import hashlib
def hash_pass(p): return hashlib.md5(p.encode()).hexdigest()
```

# Secure Patterns
Secure implementation fulfilling ASVS V6.2.1:
```python
from argon2 import PasswordHasher
ph = PasswordHasher()
def hash_pass(p): return ph.hash(p)
```

# Python Example
```python
from argon2 import PasswordHasher
ph = PasswordHasher()
def hash_pass(p): return ph.hash(p)
```

# FastAPI Example
```python
pwd_context = CryptContext(schemes=['argon2', 'bcrypt'], deprecated='auto')
```

# Flask Example
```python
hash_str = generate_password_hash(password, method='pbkdf2:sha256', salt_length=16)
```

# Django Example
```python
PASSWORD_HASHERS = ['django.contrib.auth.hashers.Argon2PasswordHasher']
```

# PostgreSQL Considerations


# Common Developer Mistakes
Implementing custom encryption logic or reusing static initialization vectors (IV).

# False Positives
Using MD5 or SHA1 strictly for non-security checksums (e.g. file cache keys).

# False Negatives
Using strong ciphers but hardcoding the secret encryption key in source code.

# AI Review Heuristics
Flag any usage of MD5, SHA1, DES, or ECB mode in password or encryption workflows.

# Detection Confidence
Confidence level: **HIGH**

# Reasoning Chain
Inspect algorithm parameters in hashing/encryption calls and flag obsolete ciphers.

# Review Checklist
- [ ] Verify requirement ASVS V6.2.1 is enforced in code.

# Remediation
Migrate password hashing to Argon2id/bcrypt and symmetric encryption to AES-256-GCM.
