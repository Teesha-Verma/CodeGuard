# Retrieval Summary
OWASP ASVS V9.1.1 requires tls protocol configuration and cipher suite security. This verification rule ensures applications enforce ensure all client-server and server-server network channels enforce secure tls protocols. to prevent supporting obsolete sslv3 or tls 1.0 protocols leaves communication channels vulnerable to downgrade attacks. across Python web frameworks including FastAPI, Flask, and Django.

# Overview
Verify that all network communications use TLS 1.2 or TLS 1.3 with strong cipher suites.

# Official Requirement
Verify that the application complies with OWASP ASVS V9.1.1 (V9 Communications): Verify that all network communications use TLS 1.2 or TLS 1.3 with strong cipher suites.

# Security Objective
Ensure all client-server and server-server network channels enforce secure TLS protocols.

# Why This Matters
Supporting obsolete SSLv3 or TLS 1.0 protocols leaves communication channels vulnerable to downgrade attacks.

# Threat Model
Attacker conducts man-in-the-middle attack to force client connection downgrade to TLS 1.0.

# Detection Guidance
AI code reviewers should scan Python source files for unvalidated usage of ssl.create_default_context, ssl.PROTOCOL_TLS_CLIENT. Look for missing authorization, improper type checking, or un-parameterized dynamic input.

# AST Detection Hints
Target AST nodes: `ast.Call (ssl.create_default_context, ssl.SSLContext)`. Scan function definitions and calls matching these nodes.

# Regex / Search Hints
Use regex pattern: `(?i)(PROTOCOL_SSLv23|PROTOCOL_TLSv1|PROTOCOL_TLSv1_1)` to flag candidate vulnerabilities.

# Semantic Detection Hints
Configuring SSL contexts to allow deprecated TLS protocols or insecure cipher choices.

# Relevant Python APIs
`ssl.create_default_context, ssl.PROTOCOL_TLS_CLIENT`

# Relevant Imports
`import ssl`

# Vulnerable Patterns
Insecure implementation exposing security flaws:
```python
context = ssl.SSLContext(ssl.PROTOCOL_TLSv1) # VULNERABLE
```

# Secure Patterns
Secure implementation fulfilling ASVS V9.1.1:
```python
context = ssl.create_default_context()
context.minimum_version = ssl.TLSVersion.TLSv1_2 # SECURE
```

# Common Developer Mistakes
Disabling SSL certificate verification (`verify=False` in requests module).

# False Positives
Internal loopback socket communication between processes on the same isolated host.

# False Negatives
Enforcing TLS 1.2 on web traffic while leaving backend database connections unencrypted.

# AI Review Heuristics
Flag any SSLContext setup allowing TLS versions below 1.2 or setting `check_hostname = False`.

# Detection Confidence
Confidence level: **HIGH**

# Reasoning Chain
Verify minimum protocol version settings in SSLContext instantiations.

# Review Checklist

- [ ] Ensure secure default fallback if validation fails.

# Remediation
Set `minimum_version = ssl.TLSVersion.TLSv1_2` and restrict cipher suites to modern GCM algorithms.
